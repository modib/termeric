Configuration

Set these env vars before sourcing termeric.

Variable Default Description
PROMPT_COLOR on Master color switch: on (default) or off
PROMPT_STYLE 0 Prompt style: 0=powerline, 1=basename, 2=abbreviated, 3=full path, 4=long text
PROMPT_SHOW_USER on Show user@host segment
PROMPT_SHOW_EXIT on Show ✘ exit code indicator on failure
PROMPT_SHOW_DIR on Show directory path
PROMPT_SHOW_SSH on Show SSH indicator when connected
PROMPT_SHOW_TIME off Show command duration when it exceeds 2 seconds

bash/zsh (in ~/.bashrc or ~/.zshrc):

export PROMPT_COLOR=on
export PROMPT_STYLE=0
export PROMPT_SHOW_USER=on
export PROMPT_SHOW_EXIT=on
export PROMPT_SHOW_DIR=on
export PROMPT_SHOW_SSH=on
export PROMPT_SHOW_TIME=off

fish (in ~/.config/fish/config.fish):

set -g PROMPT_COLOR on
set -g PROMPT_STYLE 0
set -g PROMPT_SHOW_USER on
set -g PROMPT_SHOW_EXIT on
set -g PROMPT_SHOW_DIR on
set -g PROMPT_SHOW_SSH on
set -g PROMPT_SHOW_TIME off

CLI Commands

Command Description
termeric install Install prompt files and add source lines to shell config
termeric install --font Install along with Meslo Nerd Font
termeric uninstall Remove prompt files and source lines
termeric update Pull latest version from git and reinstall
termeric config Open configuration in $EDITOR
termeric status Show installed state, toggles, and cache status
termeric font Install Meslo Nerd Font (bundled or via Homebrew)
termeric doctor Check system compatibility — shell, git, terminal, font
termeric version Show installed version

Troubleshooting

Prompt looks like raw escape codes

Make sure PROMPT_COLOR=on is set before sourcing termeric. Your terminal must support 256color or truecolor. Check with: echo $TERM — should end in -256color or -truecolor.

Powerline arrows show as broken characters

Install a Nerd Font: termeric font, then set your terminal to use "MesloLGL Nerd Font". The arrow characters ( / ) require a patched font.

Prompt conflicts with oh-my-zsh / powerlevel10k

Termeric detects conflicting prompt customizations during install. Comment out the existing prompt setup in ~/.zshrc, or run termeric uninstall to revert.

Git status not showing

You need git installed and the directory must be a git repository. Run termeric doctor to verify. The git status cache lives in ~/.cache/termeric/.

Updates and upgrades

If installed via git: termeric update. If installed via Homebrew: brew upgrade termeric. If installed via install.sh: re-run the curl pipe or clone fresh.
