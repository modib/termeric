Why termeric?

Git status caching with sub-10ms prompt rendering. No more waiting for your prompt.

24-bit truecolor segments with smooth arrow separators. Looks great in any modern terminal.

🔧

Three Shells

Full support for bash, zsh, and fish with visual parity across all three.

📦

Bundled Font

MesloLGS Nerd Font included. No extra downloads needed — just install and go.

🧹

Clean Config

Simple env vars for features. No complex config files to maintain.

Easy Install

One command setup via Homebrew, deb, rpm, AUR, or direct install.
